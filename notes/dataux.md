It is stored in errors.title so we can display the exact error message directly under the title input field. If we used one general error message for the whole form, the user wouldn't easily know which specific input they need to fix.Q6: What does aria-live actually do, and why does a loading message need it even though a sighted user can already see the screen change?
The aria-live attribute tells screen readers to automatically announce when the content inside that element changes. A sighted user can see the text change to "Loading...", but a visually impaired user needs aria-live so their screen reader reads the update out loud without them having to manually search the page for changes.
